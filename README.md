# 🌿 NUURAI

An AI-powered mental wellness platform designed to help users understand patterns in their mood, energy, stress, and overall wellbeing through daily check-ins and personalized insights.

## ✨ Features

- 🌱 Daily mood & wellness check-ins
- 📊 Energy and stress tracking
- 📈 Weekly pattern insights
- 📝 Personal reflection & journaling
- 💬 AI wellness companion
- 📱 Clean & responsive interface

## 🛠️ Tech Stack

- React
- JavaScript
- CSS
- Vite
